Why two blocks that look almost the same

Both live in the same Gmail inbox (arnoldo@ is the account, hi@ is an alias on it) — only the reply-from address changes. Use block 1 when you're writing as yourself, block 2 when you're replying as the studio's general inbox. Gmail lets you set a default signature per "send as" address under Settings → Accounts, so each one attaches automatically.

How to install

Gmail: open this page in a browser. For each block, click inside the dashed box, press Cmd/Ctrl+A then Cmd/Ctrl+C. In Gmail go to Settings → See all settings → General → Signature → Create new, paste it in, then under Settings → Accounts assign it to the matching "send mail as" address.

Apple Mail: select and copy the box the same way, then paste directly into Mail → Settings → Signatures. Apple Mail sometimes strips images pasted this way — if the logo or banner doesn't appear, drag the box's content in from the browser instead of using keyboard copy/paste.

Outlook: copy the box, then in Outlook go to File → Options → Mail → Signatures → New, and paste into the editor. Desktop Outlook renders email less faithfully than other clients — check the image sizes still look right after pasting.
